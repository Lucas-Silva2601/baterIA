# 🎤 APRESENTAÇÃO DO PROJETO

**Bateria Virtual com IA**  
**Versão 1.0.0**

---

## 🎯 ELEVATOR PITCH (30 segundos)

> **Bateria Virtual com IA** é uma aplicação web moderna que permite tocar bateria virtualmente, criar loops profissionais e conversar com uma IA para gerar ritmos incríveis. Desenvolvida em React com integração da Groq API, oferece uma experiência interativa e divertida para músicos e entusiastas.

---

## 🚀 O QUE É?

Uma aplicação web completa que combina:
- 🥁 **Bateria Virtual** - 9 instrumentos interativos
- 🔄 **Sistema de Loop** - 3 BPMs profissionais
- 🤖 **IA Integrada** - Chat inteligente com Groq
- 🎨 **Interface Moderna** - Design elegante e responsivo


## 🚀 INÍCIO RÁPIDO (5 MINUTOS)

### Passo 1: Instalar
```bash
cd bateria-ia-react
npm install
```

### Passo 2: Configurar
```env
VITE_GROQ_API_KEY=sua_chave_aqui
```

### Passo 3: Iniciar
```bash
npm run dev
```

### Passo 4: Acessar
```
http://localhost:5173
```
